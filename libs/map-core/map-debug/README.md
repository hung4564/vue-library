# Map Debug Library

The **Map Debug** library provides a set of devtools UI components for visualizing map state, logs, and debugging information. It integrates with both Vue and React adapters.

## Packages
- `@hungpvq/vue-map-devtools` – Vue components for devtools panel, log viewer, error inspector.
- `@hungpvq/react-map-devtools` – React equivalents of the Vue devtools.

## Documentation
- API reference: `libs/map-core/map-debug/docs/api.md`
- Usage guide: `libs/map-core/map-debug/docs/quick-start.md`
- Component reference: `libs/map-core/map-debug/docs/components/*.md`

npm run map:lint        # lint + type‑check map‑debug
npm run map:test        # run Vitest unit tests for map‑debug
