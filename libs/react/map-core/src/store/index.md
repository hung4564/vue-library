# Map Store

Canonical docs: [Map store](/map/core/map-store) (hub under `@hungpvq/map-core`).

Framework adapters expose scoped store helpers (`createMapScopedStore` / `getStore`). The MapLibre instance is accessed with **`getMap` from `@hungpvq/map-core`** (one map per `mapId`). Theme / `registerMapAccessor` are process-global — see the hub page.
