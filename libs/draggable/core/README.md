# Draggable Core Library

The **Draggable Core** library provides framework‑agnostic utilities for building drag‑and‑drop layouts. It includes a store, type definitions, and core algorithms used by both Vue and React adapters.

## Documentation
- API reference is in `libs/draggable/docs/` (currently minimal).
- Usage example:
```bash
npm install @hungpvq/draggable
```
- Import the store and utilities in your UI framework.

## Development
```bash
npm run draggable:lint   # lint + type‑check
npm run draggable:test   # run unit tests (currently placeholders)
```
